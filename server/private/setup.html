DayOne

Owner settings

This restricted page connects ElevenLabs to this deployed website. It does not place a call or send an SMS.

  1. In Render → this service → Environment, set ELEVENLABS_API_KEY with agent and tool permissions. The Blueprint generates SESSION_SECRET. Never put keys in GitHub.
  2. Render generates TOOL_SECRET. Enter it below to authorize the setup operation. It is not saved in browser storage.
  3. For real SMS, configure VOBIZ_AUTH_ID, VOBIZ_AUTH_TOKEN, and VOBIZ_SENDER_ID (a messaging-enabled number), then set SMS_PROVIDER=vobiz. Country-specific registration may also be required.


Free Render hosting sleeps when idle. Local generated sites are temporary. Telephone calls also need working Vobiz SIP routing and provider credit.
