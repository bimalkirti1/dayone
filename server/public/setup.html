DayOne

Connect your live agents

This owner-only setup connects ElevenLabs to this deployed website. It does not place a call or send an SMS.

  1. In Render → this service → Environment, add ELEVENLABS_API_KEY with Agents read/write access and tool access. The Blueprint generates SESSION_SECRET for you. Never put keys in GitHub.
  2. The Blueprint generates TOOL_SECRET. Paste its value into the password field below. It is sent only to this website’s protected setup endpoint and is not saved in your browser.
  3. To send real SMS later, add VOBIZ_AUTH_ID, VOBIZ_AUTH_TOKEN, and VOBIZ_SENDER_ID (a messaging-enabled number), then set SMS_PROVIDER=vobiz. Recipient-country registration may also be required.


Free Render hosting sleeps when idle. Generated site links are temporary and will stop working after local data is reset. Phone routing and Vobiz account credit must also be configured. Use paid persistent storage before serving real customers.
